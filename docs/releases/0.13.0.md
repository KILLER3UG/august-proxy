> **Released:** 2026-08-08
> **Previous release:** [0.12.22–0.12.36](./0.12.22-36.md) (desktop batch)
> **Status:** One release cut after the audit pass + four feature batches.
> Bundled backend: yes — desktop installs must ship the backend changes below.

## Highlights

### Skills self-improvement — versioned heuristics with rollback + skill promotion

`feat: skills self-improvement (versioned heuristics + rollback + skill
promotion) + hardening` (`4812d2ff`). The last parked roadmap item (Prime
/refine pattern):

- **Version history**: every heuristic mutation records a trail entry
  (`add`/`upgrade`/`edit`/`suppress`/`restore`/`remove`/`rollback`); new
  `GET /api/brain/heuristics/{id}/trail` + `POST …/rollback` restore the
  previous rule text — per-row History + Rollback in the Brain You tab.
- **"Keeps winning" bookkeeping**: migration `012` adds `use_count` +
  `last_surfaced_at` to `learned_heuristics`; the prompt builder bumps
  `use_count` for every injected rule (visible as "used N×").
- **Skill promotion**: rules injected ≥8 times at ≥80% confidence are
  queued as pending-skill proposals each consolidation cycle — approved
  via the Brain Learning tab (diff + approve/reject) with a "new" badge.

### Evidence-driven auto-routing (closed loop)

`feat: evidence-driven auto-routing v2` (`28abee8e`). The routing-evidence
consult (surpass #1) is now a first-class, UI-controlled feature:

- Brain config gains `autoRoute` + threshold knobs (`autoRouteMinSamples`,
  `autoRouteMinWinRate`, `autoRouteWinGap`) — new `float` field kind in
  `brain_config_service.validatePatch`, exposed via `GET/PUT /api/brain/config`.
- Flap guard: a candidate must beat the CURRENT model's win rate by the gap
  threshold (or the current model has no evidence yet) — no oscillation
  between two good models. `AUGUST_AUTO_ROUTE=1` still forces on.
- Measured: routed turns record `source='auto-route'` (still counting toward
  model win rates) and every decision lands in the
  `routing:auto-route:decisions` KV log.
- UI: Reliability dashboard toggle + thresholds + "Best model per task type"
  table + "Recent auto-route decisions"; routed turns raise a notification
  (new `routing` notification kind) so reroutes are never silent.
- Endpoints: `GET /api/brain/routing/best-by-task`, `GET /api/brain/routing/decisions`.

### Self-improvement loop (turn-level lessons)

`feat: self-improvement lessons, scheduled golden evals, arena replay, bug
batch` (`3c51f756`). Failed turns record `provider_reliability` heuristics
(upstream errors, stall hard-stops, format rejections); verifier blocks record
`verifier` correction lessons — merged/confidence-bumped on repeats, scrubbed
of secrets, injected into future system prompts (top-N by confidence) with
rollback/suppress UI in the Brain You tab. Verified end-to-end via the eval
scenarios.

### Scheduled golden evals

`run_turn` works without pytest (`_DirectPatch`), so the 7-scenario golden
suite (well-behaved, tool round-trip, malformed self-heal, empty-response,
stall detection, verifier block/pass) runs through the REAL loop every 6h from
app boot, plus on demand via `POST /api/brain/harness/evals/run` — with a
"Run evals now" button in the Reliability dashboard. Verified 7/7 passing.

### Multi-agent workspace: Agent Board at /board + team launching

`feat: Runs view + Reliability dashboard` (`ace12439`) and the board batch
(this release). The durable kanban board moved from its hidden settings
section to a top-level **Board** tab (`/board`, sidebar nav): launch a team
(one sub-agent per goal line), auto-create a board card per goal, and
live-sync card columns to run status (running → doing, completed → done,
failed → backlog). Board cards now carry `taskId` for run linkage.

### Runs view with retry / cancel

`feat: Runs view` (`ace12439`) + retry/cancel batch. `/runs` lists every
workbench session as a run: stat strip (total / active / awaiting /
completed / tokens·cost), status filters, model · tokens · cost · duration,
**Open** (resumes in chat), **Retry** (re-sends the last user message with
the run's model), and **Cancel** (stops the active stream).

### AI Setup wizard, Data & Privacy, health simulator, debate verdicts

`feat: AI Setup wizard, Data & Privacy center, health simulator, debate
verdicts` (`2947afd4`):

- `/settings/ai-setup` — guided 6-step first-run wizard (provider → test →
  models → default → safety mode → start); becomes the `/settings` landing
  while setup is incomplete; the safety-mode choice writes the same
  `august_last_sandbox_mode` key new sessions read (first-run safety choice).
- `/settings/privacy` + `app/routers/privacy.py` — storage summary, JSON
  export, memory purge, log/screenshot clearing, usage deletion,
  cascade-aware session deletion.
- `/settings/health-simulator` + `POST /api/providers/simulate` — real
  connectivity, tool-support, and fallback-route probes (`testModel` shares
  `_probe_connectivity`).
- Finished debates get a "who made the better case?" row that records the
  verdict to `/api/brain/routing/arena` — judged debates feed the evidence
  loop like arena comparisons.

### Settings restructure + onboarding fixes

`feat: settings restructure (5 groups), onboarding fixes, actionable chat

original prompt; the arena archive groups per verdict with winner/loser chips
and **Replay** re-runs the same lanes on the stored prompt (shared
`launchArenaRun`).
