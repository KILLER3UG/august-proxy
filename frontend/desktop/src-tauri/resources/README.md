# Desktop backend resources

Generated by `node scripts/prepare-desktop-backend.mjs`.
Do not commit the python/ / backend-py/ / wheels/ / ngspice/ trees —
CI/release builds them.

## The stamp landmine

backend-runtime.stamp and backend-runtime.json here are generated by
prepare-desktop-backend.mjs and GITIGNORED for a reason: a dev build
(debug_assertions) must never treat them as the installer payload —
bootstrapBundledBackend refuses to bootstrap in debug builds, because a
leftover real stamp made `tauri dev` wipe the installed AppData runtime
on stamp mismatch (fixed 2026-10-30, Stage 4). If you generated a local
payload for testing, delete the stamp + json before running dev:desktop.
