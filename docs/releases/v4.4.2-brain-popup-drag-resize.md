# v4.4.2 — Brain Popup Drag & Resize (rolled back)

> **Released:** 2026-06-30 (approx)
> **Status:** **Rolled back** — feature source and tests were deleted in
> commit `1b796ffe` (2026-07-24). This note exists to fill the gap between
> [`v4.4.1-brain-popup`](./v4.4.1-brain-popup.md) and
> [`v4.4.4-popup-image-like-resize`](./v4.4.4-popup-image-like-resize.md),
> which both reference it.
> **Previous release:** [v4.4.1-brain-popup](./v4.4.1-brain-popup.md)

## What this was

An iteration on the floating brain popup that added a **single SE-corner
resize handle** and **header-only drag**, addressing the v4.4.1 feedback that
the popup could not be moved or resized.

## Why it was rolled back

Per [`v4.4.4-popup-image-like-resize.md`](./v4.4.4-popup-image-like-resize.md):

- The single SE-corner handle only adjusted height in practice — the user
  reported *"i can't move it anywhere and i can only adjust the height."*
- The drag test (`v4_4_2_brain_popup_drag_resize.test.tsx`) was **passing by
  accident**: `fireEvent.pointerMove(document, …)` attaches props to the
  React synthetic event, but the popup uses **native** document listeners
  (it's portaled to `document.body`), so the listener saw a bare event with
  no `clientX` and computed `NaN` positions.

v4.4.4 replaced the whole approach (drag-from-anywhere + 8 resize handles +
native `MouseEvent` dispatch). The v4.4.2 source files (`ResizeHandles.tsx`,
`usePopupDrag.ts`, `usePopupResize.ts`, `popupGeometry.ts`) and their tests
were later removed alongside the rest of the brain-popup feature in
`1b796ffe`.
