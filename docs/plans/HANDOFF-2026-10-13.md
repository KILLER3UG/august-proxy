## 5. Environment facts that cost time

- `git checkout -- <file>` discards uncommitted work in it. Use byte copies for red/restore
  cycles; snapshots in `/tmp` go stale the moment you edit again.
- Bash heredocs eat backslashes: `'\\'` in a heredoc-patch script lands as `'\'`. `_GUARD_TEMPLATE`
  in `code_runner.py` is a **raw** triple-quoted string, so `r'\s+'` must be written with one
  backslash there.
- `monkeypatch.undo()` inside a test also undoes the `isolatedData` fixture's env (same
  instance) — resolve any path you still need **before** calling it.
- `tail.exe` intermittently dies with "couldn't create signal pipe" under load; re-run rather
  than trust the failure.
