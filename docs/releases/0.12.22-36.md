## Highlights

### Auto-update approach changed (v0.12.34, 2026-07-23)

`feat(desktop): update via full GitHub release installer instead of quiet
patch` (`8e798541`). Windows now downloads the full NSIS setup
(`August_<version>_x64-setup.exe`) via the Rust `download_release_installer`
command, stops the backend, and calls `launch_installer_and_exit` — the user
walks through the setup wizard like a first install. This deliberately
replaced the earlier quiet in-place patch, which could miss bundled backend
changes. Non-Windows keeps the in-place `@tauri-apps/plugin-updater` path.
See `frontend/desktop/src/hooks/useAppUpdate.ts:109-175` and
`src-tauri/src/backend.rs:1142-1262`. A follow-up build fix
(`cc1dbd0f`, 2026-07-23) resolved a compile error in the installer download
path (blocking `reqwest` had no `chunk()`).

### Model context window + Test button fixes (v0.12.36, 2026-07-25)

`fix(models): context window stuck at 128k + Test button 'Not found'`
(`0f5622f5`). `model_service.py:95-102` now honors a stored per-model
`contextWindow` whether the source is `'fetched'` or manual (previously a
128000+fetched entry was treated as unset and fell through to heuristics that
also returned 128000 for deepseek/kimi/gpt-4o). Provider model routes now use
the `{modelId:path}` converter (`providers.py:328/365/387`) so models whose ids
contain slashes no longer 404 on Test/update/delete. The Test probe accepts
any non-empty reply as success.
