## What's new

Closes the last big user-facing gap in the Brain dashboard: **the brain now tells you what it's doing in realtime**. When the consolidation daemon merges duplicate heuristics, when the delta engine infers a preference from your edit, when the background review reflects on a session, when skill genesis drafts a new skill — you see it happen.

### Architecture

```
┌─ Subsystems (5 publishers) ─┐   ┌─ Brain Event Bus ─┐   ┌─ /api/brain/events ─┐   ┌─ BrainActivityTab ─┐
│ consolidation_daemon         │──▶│  in-process       │──▶│  GET (recent)       │──▶│  Live SSE feed      │
│ delta_engine.flush_queue     │   │  ring buffer      │   │  + SSE stream       │   │  + chip filters    │
│ heuristics_service.add_heur  │   │  + SSE fan-out    │   │                     │   │  + pause toggle    │
│ background_review._do_review │   └───────────────────┘   └─────────────────────┘   └─────────────────────┘
│ consolidation_daemon.{draft,│
│   approve,reject}_skill      │
└──────────────────────────────┘
```

### Backend

- **`app/services/brain_event_bus.py`** — in-process pub/sub. 200-event ring buffer + SSE fan-out (parallel to `services/logger.py:ActivityLog`).
- **`app/routers/brain_activity.py`** — `GET /api/brain/events?limit=&category=` + `GET /api/brain/events/stream` (SSE).
- **5 publishers** wired into existing subsystems (all defensive: try/except + log + never break the underlying op):
  - `consolidation_daemon.run_consolidation` → start + done events (with merge/promote/delete counts)
  - `heuristics_service.add_heuristic` → per-rule event with rule_id + source
  - `delta_engine.flush_queue` → batch event with local-vs-llm split
  - `background_review._do_review` → start + done events (skill recs + fact recs)
  - `consolidation_daemon.{draft,approve,reject}_pending_skill` → skill_genesis category

### Frontend

- **`api-client.ts`** — `getBrainEvents(limit?, category?)` + `openBrainEventStream()` returning a browser `EventSource`.
- **`sections/brain/BrainActivityTab.tsx`** — feed of `{at, category, summary}` rows, 6 chip filters (All / Consolidation / Heuristics / Delta Engine / Review / Skill Genesis), Pause toggle, auto-merging REST-recent + SSE-live streams (deduped by id).
- **`BrainDashboard.tsx`** — added **Activity** as the **3rd tab** (between Learning and System Health), with `Activity` icon from lucide-react.
