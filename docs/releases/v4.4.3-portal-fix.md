# v4.4.3-portal-fix — Brain Popup Portal Escape (rolled back)

> **Released:** 2026-06-30 (approx)
> **Status:** **Rolled back** — feature source and tests were deleted in
> commit `1b796ffe` (2026-07-24). This note exists to fill the gap referenced
> by [`v4.4.4-popup-image-like-resize.md`](./v4.4.4-popup-image-like-resize.md),
> whose "Previous release" link points here.
> **Previous release:** [v4.4.2-brain-popup-drag-resize](./v4.4.2-brain-popup-drag-resize.md)

## What this was

A bug fix for the floating brain popup: when rendered with `position: fixed`
inside the titlebar on the chat route, framer-motion's transform containing
block **trapped** the popup so it could not escape the titlebar area. The fix
rendered the popup via `createPortal(document.body)` so `position: fixed`
escaped the transformed ancestor.

## Why it was rolled back

The portal approach worked but was superseded by the v4.4.4 redesign
(drag-from-anywhere + 8 resize handles). When the entire brain-popup feature
was later removed (commit `1b796ffe`, 2026-07-24), the `BrainPopup.tsx`,
`brain-indicator/` directory, and the `v4_4_3_portal_escape.test.tsx` test
were deleted together.

See [`../GAPS_AND_BUGS.md`](../GAPS_AND_BUGS.md) for the open tracking of this
release-notes gap.
